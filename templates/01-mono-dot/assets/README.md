# 에셋 요청서 — 01 모노크롬 도트 (DOTLINE)

이 템플릿은 외부 이미지 없이도 완성된 상태로 보입니다. 모든 도트 그래픽은 `main.js`의 `// ── SPRITES ──` 구역에
문자열 지도(한 글자 = 도트 1개)로 들어 있고, 코드가 원형 LED 도트로 다시 그립니다.
실제 파일이 준비되면 이 폴더에 넣고 `main.js` 맨 위 `ASSETS`의 값을 `null`에서 파일 경로로 바꾸면 됩니다.

```js
const ASSETS = {
  heroFrames: 'assets/hero-frames.png',
  featureFrames: null,
  caseIcons: null,
  logo: 'assets/logo.svg',
  productShot: null,
};
```

## 1. 이미지 에셋

| 파일명 | 용도 (어디에 쓰이나) | 규격 | 팔레트 제한 | 우선순위 | 연결 방법 |
|---|---|---|---|---|---|
| `logo.svg` | 헤더·푸터 브랜드 마크 (지금은 5×5 도트 "D") | 정사각 SVG, 20×20px로 표시. 5×5 도트 그리드 권장 | `#F2F2EC` + 강조점 `#F05243` 1개, 배경 투명 | 필수 | `ASSETS.logo` |
| `hero-frames.png` | 첫 화면 상징물. 4개 모양이 도트 단위로 천천히 바뀜 (끝의 CTA 띠에도 첫 프레임 사용) | 100×25px PNG. 25×25 프레임 4개를 가로로: ① LISTEN(얼굴) ② TRANSCRIBE(파형) ③ EXTRACT(할 일) ④ DRAFT(문서). 1px = 도트 1개, 안티앨리어싱 없이 | 꺼진 도트 `#111214`(또는 `#313132`), 켜진 도트 `#F2F2EC`, 강조 `#F05243`, 투명 = 도트 없음(원형 디스플레이 바깥) | 권장 | `ASSETS.heroFrames` — 넣으면 깜빡임·재생 헤드 같은 세부 움직임은 꺼지고 4프레임 전환만 남습니다 |
| `feature-frames.png` | 주요 기능 탭(회의 요약/할 일 추출/문서 초안)을 고를 때 바뀌는 도트 패널 | 31×39px PNG. 31×13 프레임 3개를 세로로 (요약 → 할 일 → 문서). 가운데 화살표(3열) 위치 유지 권장 | 위와 동일 | 선택 | `ASSETS.featureFrames` |
| `case-icons.png` | 사용 사례 4종 아이콘 | 36×9px PNG. 9×9 아이콘 4개를 가로로: 주간 회의 · 고객 인터뷰 · 강의 · 1:1. 63px(7배)로 표시 | `#F2F2EC` + 아이콘마다 `#F05243` 1점, 나머지 투명 | 선택 | `ASSETS.caseIcons` |
| `product-screen.png` | "실제 사용 화면" 자리의 앱 화면 (지금은 HTML 목업) | 2400×1500px 이상(2배 해상도), PNG 또는 WebP, 다크 테마 화면 | 화면 자체 색 | 선택 — HTML 목업 유지를 권장(선명하고 문구 수정이 쉬움) | `ASSETS.productShot` — 목업 대신 이미지 한 장으로 바뀜 |
| 파비콘 | 브라우저 탭 아이콘 | 32×32 SVG 또는 PNG | 로고와 동일 | 권장 | `index.html`의 `<link rel="icon">` 데이터 URI 교체 |
| `og-image.png` | 링크 공유 미리보기 | 1200×630px PNG | 팔레트 내 | 선택 | `<head>`에 `og:image` 메타 태그 추가 |

**PNG 제작 규칙**
- 도트 하나 = 픽셀 하나. 확대·축소는 코드가 정수 배율로 처리하니 원본 크기 그대로 저장합니다.
- 위 4가지 색만 씁니다. 비슷한 색은 가장 가까운 팔레트 색으로 바뀌고, 알파값 50% 미만은 "도트 없음"이 됩니다.
- 상징물은 모양마다 빨간 점을 1~3개 이내로 둡니다. 빨강은 선택 상태·작은 신호에만 씁니다.
- 파일을 읽지 못하면 콘솔 경고만 남기고 기본 도트 그림으로 돌아갑니다.

## 2. 이미지 외에 받아야 할 것

- **서비스 이름·로고 확정** — `DOTLINE / 도트라인`은 가상 이름입니다. 워드마크는 Doto 글꼴로 그려집니다.
- **실제 수치** — 핵심 가치(38초, 92%, 주 4시간)와 사용 사례(10분, 24건, 7개, D-1)는 예시입니다. 근거 있는 수치로 바꾸고 "예시" 각주를 지워 주세요.
- **가격·플랜** — 무료/팀(9,900원)/기업 구성, 포함 항목, 연간 결제 조건, 체험 기간.
- **제품 화면 문구** — 목업 속 회의 제목·참석자 이름·할 일은 가상 데이터입니다. 실제 고객 정보는 넣지 마세요.
- **FAQ 답변** — 녹음 보관 위치·기간, 참석자 동의 절차는 법무·보안 검토 후 확정합니다.
- **링크** — 가입(`#signup`), 상담(`#contact`), 로그인, 개인정보처리방침, 이용약관, 채용, 회사 소개, 서비스 상태 페이지(푸터 `ALL SYSTEMS NORMAL`).
- **지원 언어** — 한국어·영어·일본어(베타) 표기가 맞는지 확인.
- **글꼴** — Pretendard, Doto 모두 SIL OFL(상업 사용 가능). 별도 구매 불필요.
