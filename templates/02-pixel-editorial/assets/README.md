# 에셋 요청서 — 모눈 스튜디오 (02 픽셀 에디토리얼)

지금 페이지의 그림은 모두 `main.js`의 `── SPRITES ──` 구역에서 코드로 그린 예시입니다.
실제 작품 파일을 이 폴더(`assets/`)에 넣고 `main.js` 맨 위 `ASSETS` 값만 바꾸면 코드 그림 대신 파일이 보입니다.

## 연결 방법

```js
const ASSETS = {
  hero: { src: 'assets/hero-radio.png', frames: 8, fps: 6 },
  rain: { src: 'assets/work-12-rain.png', frames: 8, fps: 8 },
  // 정지 이미지는 frames 를 생략하거나 1
};
```

- **스프라이트 시트 규칙**: 프레임을 왼쪽에서 오른쪽으로 한 줄로 이어 붙인 PNG 한 장. 시트 폭 = 프레임 폭 × 프레임 수.
- 화면에서는 원본 픽셀을 **정수배로만** 키웁니다(흐릿한 확대 없음). 원본은 1배 크기로 보내 주세요. 2배·3배로 키운 파일은 받지 않습니다.
- 그림 안에서 안티앨리어싱(반투명 가장자리)·그라데이션·흐림을 쓰지 않습니다. 투명은 완전 투명(알파 0)만 씁니다.
- 대표 그림을 바꾸면 `HERO_CROPS`(프레임 필름·8배 확대 위치, 160×90 기준 좌표)와 `ASSETS.heroPalette`(팔레트 목록 hex 배열)도 그 그림에 맞게 고쳐 주세요.
- 파일을 못 불러오면 콘솔에 경고를 남기고 코드 그림으로 돌아갑니다.
