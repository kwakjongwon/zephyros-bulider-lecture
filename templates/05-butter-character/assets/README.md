# 버티(BUTTY) 템플릿 — 에셋 요청서

지금 페이지의 도트 그림은 모두 `main.js`의 `// ── SPRITES ──` 구간에 있는 픽셀 맵(문자열 배열)으로 그려집니다.
아래 파일을 이 `assets/` 폴더에 넣고 `main.js` 맨 위 `ASSETS` 설정에 경로만 적으면 코드 그림 대신 실제 파일이 쓰입니다.
파일이 없거나 불러오지 못하면 자동으로 코드 그림으로 돌아갑니다.

```js
const ASSETS = {
  spriteSheet: 'assets/butty-sheet.png',
  icons: 'assets/butty-icons.png',
  logo: 'assets/butty-logo.png',
};
```

## 1. 이미지 에셋

| 파일명 | 용도(위치) | 규격 | 팔레트 제한 | 우선순위 | 연결 방법 |
|---|---|---|---|---|---|
| `butty-sheet.png` | 버티 캐릭터 전체 포즈: 첫 화면, 각 구간 캐릭터, 반응 시연, 앱 화면 속 미니 버티 | 프레임 32×32px(논리 1px = 실제 1px, 확대는 코드가 정수 배율로 처리). 10행 × 5열, 전체 160×320px, 투명 PNG. 행 순서와 프레임 수는 아래 표 참고 | `#243E32` 외곽선·얼굴, `#F3D86A` 몸, `#FAEDB5` 윗면 하이라이트, `#D7B240` 그림자·볼, `#FFFDF4` 반사광·소품, `#E7EBDD` 소품 (6색) | 필수 | `ASSETS.spriteSheet` |
| `butty-icons.png` | 기능 소개 아이콘, 시연 버튼 아이콘, 스토어 버튼 아이콘 | 12×12px 6칸 가로 한 줄(72×12px), 투명 PNG. 순서: phone, timer, mug, flag, stamp, download | 위와 같음. `download`는 짙은 버튼 위에 놓이므로 `#FFFDF4` 한 색 | 권장 | `ASSETS.icons` |
| `butty-logo.png` | 헤더·푸터 로고 마크 | 16×16px 1프레임, 투명 PNG | 위와 같음 | 권장 | `ASSETS.logo` (파비콘은 `index.html`의 `<link rel="icon">` data URI를 같은 그림으로 교체) |
| `og-image.png` | 링크 공유 미리보기 | 1200×630px PNG. 노란 면 + 버티 + 서비스 이름 | 위 팔레트 | 선택 | `index.html` `<head>`에 `<meta property="og:image" content="assets/og-image.png">` 추가 |

### 스프라이트 시트 행 순서 (`SHEET_ROWS`)

| 행 | 포즈 | 프레임 수 | 프레임 내용 (열 순서) |
|---|---|---|---|
| 0 | idle 기본 | 3 | 기본 · 1px 위로 · 눈 깜빡임 |
| 1 | focus 집중 | 4 | 머리띠+연필 · 연필/매듭 흔들림 · 땀방울 · 전환용 살짝 뜀 |
| 2 | rest 휴식 | 3 | 머그잔+김 A · 김 B · 전환용 살짝 뜀 |
| 3 | done 완료 | 5 | 깃발 A · 2px 점프 · 4px 점프 · 깃발 B · 착지(1px 눌림) |
| 4 | worried 딴짓 감지 | 2 | 느낌표+땀 · 1px 위로 |
| 5 | wave 손 흔들기 | 3 | 팔 위 A · 팔 위 B · 눈 깜빡임 |
| 6 | cheer 인사 | 2 | 두 팔 위 · 1px 위로 |
| 7 | point 안내 | 3 | 지시봉 · 지시봉 1px 위 · 눈 깜빡임 |
| 8 | celebrate 축하 | 2 | 두 팔+색종이 A · B |
| 9 | think 고민 | 3 | 물음표 · 1px 위로 · 눈 깜빡임 |

그리기 규칙: 몸통은 20×17px 버터 블록(3행 윗면 하이라이트, 오른쪽 1열·아래 1행 그림자), 1px `#243E32` 외곽선, 빛은 왼쪽 위.
바닥 그림자는 시트에 그리지 마세요. 배경색(노랑/크림/세이지)에 맞춰 코드가 따로 그립니다.
몸통 위치(가로 6–25, 세로 9–25)는 모든 프레임에서 같게 유지해야 포즈 전환이 튀지 않습니다. 애니메이션 타이밍은 `POSES`의 `loop`/`intro`(ms)에서 조절합니다.

## 2. 이미지 외에 받아야 할 것

- **서비스 이름·로고 확정**: ‘버티 / BUTTY’는 가칭입니다.
- **실제 앱 화면 기준**: ‘실제 화면’ 구간과 첫 화면 휴대폰은 HTML/CSS 목업입니다. 실제 화면 디자인이나 캡처를 주시면 같은 구조로 숫자·문구·배치를 맞춥니다(이미지로 넣지 않고 HTML로 유지 권장).
- **스토어 링크 2개**: 현재 `href="#"`. 공식 App Store / Google Play 배지를 쓰려면 각 스토어의 배지 가이드라인 파일을 받아 교체하세요(지금은 일반 버튼).
- **가격·할인 정책**: 버티 플러스 월 2,900원, 연 29,000원, 학생 40% 할인, 7일 무료 체험은 모두 예시 수치입니다.
- **FAQ 답변 확정**: 앱 차단 범위, 백업 방식, 위젯 종류, 지원 OS(iOS 16·Android 10 이상은 예시).
- **기능 문구 확인**: 집중 25분 / 휴식 5분 기본값, ‘알림 멈춤’ 동작 설명이 실제 앱과 같은지.
- **말풍선 문구**: 12자 이내 유지(`index.html`과 `main.js`의 `DEMO_STATES`).
- **법적 링크**: 이용약관, 개인정보처리방침, 문의하기 주소.
- **효과음(선택)**: 상태 전환 효과음을 원하면 8비트 짧은 효과음 3종(MP3/OGG, 각 30KB 이하, 사용 허가 확인). 현재 코드에는 연결 지점이 없어 추가 작업이 필요합니다.
