# 도트 홈페이지 템플릿 5종

픽셀 아트·도트 매트릭스를 각기 다른 방식으로 쓰는 홈페이지 템플릿입니다.
빌드 없이 HTML·CSS·JS만으로 동작하고, Firebase Hosting에 그대로 올라갑니다.

## 열어 보기

```bash
python3 -m http.server 8000
# http://localhost:8000/templates/  ← 5종 목록
```

배포 후에는 `/templates/`에서 목록을, `/templates/01-mono-dot/`처럼 폴더 주소로 각 템플릿을 엽니다.

| 폴더 | 버전 | 예시 브랜드(가상) | 도트 활용 |
|---|---|---|---|
| `01-mono-dot/` | 모노크롬 도트 | DOTLINE · AI 업무 정리 도구 | 25×25 원형 도트 상징물, 숫자·상태 표시 |
| `02-pixel-editorial/` | 픽셀 에디토리얼 | MONUN STUDIO · 픽셀 아트 스튜디오 | 작품 7점(누르면 루프 재생), 섹션 번호·화살표 |
| `03-desktop-hideout/` | 데스크톱 아지트 | HIDEOUT.FM · 음악 채널과 작업 기록 | 16×16 아이콘, 마스코트 모모, 도트 이퀄라이저 |
| `04-night-diorama/` | 밤의 디오라마 | 밤항구 NIGHT HARBOR · 인디 게임 | 시차 이동 항구 풍경, 스크롤로 켜지는 창문 |

## 폴더 구조 (템플릿마다 동일)

```
NN-slug/
├── index.html        시맨틱 마크업, 한국어 문구
├── style.css         색은 :root 토큰으로만 (역할: 배경·면·본문·강조 + 파생 1~2개)
├── main.js           ES 모듈. 맨 위 ASSETS 설정 → // ── SPRITES ── 구역 → 화면 로직
└── assets/README.md  에셋 요청서 (파일명·규격·팔레트·우선순위·연결 방법)
```

## 에셋 교체 방식

지금 보이는 도트 그림은 전부 `main.js`의 `// ── SPRITES ──` 구역에 있는 픽셀 맵(문자열 배열)을 코드가 그린 임시 이미지입니다.
실제 PNG를 `assets/`에 넣고 `main.js` 맨 위 `ASSETS`의 `null`을 파일 경로로 바꾸면 그 파일로 교체됩니다.
파일을 못 불러오면 콘솔 경고만 남기고 코드 그림으로 돌아갑니다.

- PNG는 **1배 원본 크기**(1px = 도트 1개)로 저장합니다. 확대는 코드가 정수 배율로만 합니다.
- 안티앨리어싱·반투명 가장자리·흐림을 쓰지 않습니다.
- 애니메이션은 프레임을 가로 한 줄로 이어 붙인 스프라이트 시트 한 장으로 받습니다.

## 공통 규칙

- 한글 본문은 Pretendard. 픽셀 글꼴(Galmuri, Doto)은 로고·짧은 제목·숫자·라벨에만 씁니다.
- 템플릿마다 색 역할 4개를 고정하고, 파생색은 `:root`에 이유와 함께 선언합니다.
- 첫 화면에 서비스 설명과 주요 행동 버튼을 함께 둡니다.
- 네온·글로우·노이즈 텍스처·배경 파티클·무거운 그림자는 쓰지 않습니다.
- `prefers-reduced-motion`이면 정지 프레임으로 보여 주고, 화면 밖이나 탭이 숨겨지면 애니메이션을 멈춥니다.
- 390px부터 1440px 이상까지 가로 스크롤 없이 동작합니다.

## 알아 둘 점

- 02는 지정 주황 `#D94D2B`가 밝은 바탕에서 작은 글자 대비(3.75:1)가 부족해, 버튼·작은 라벨에는 한 단계 어두운 `#BF4325`(4.68:1)를 씁니다. 원색 주황은 그래픽에만 씁니다.
- 폼은 모두 데모입니다. 03 방명록은 방문자 브라우저(localStorage)에만 저장되고, 02 문의 폼과 04 뉴스레터 폼은 화면에 안내 문구만 띄웁니다. 실제 전송처가 필요합니다.
- 숫자·가격·후기·인물·FAQ는 모두 예시 문구입니다.
