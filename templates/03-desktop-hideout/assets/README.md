# 에셋 요청서 — HIDEOUT.FM 작은 작업실 (03-desktop-hideout)

이 템플릿은 이미지·음원 파일이 하나도 없어도 완성된 화면으로 보입니다.
도트 그림은 `main.js`의 `// ── SPRITES ──` 구역에서 코드로 그리고, 음악은 **데모 모드**(진행 막대와 도트 이퀄라이저만 움직임)로 재생돼요.
아래 파일을 이 `assets/` 폴더에 넣고 `main.js` 맨 위 `ASSETS` 값만 바꾸면 실제 파일로 교체됩니다.

## 1. 이미지·음원 파일

| 파일명 | 용도 (화면 위치) | 규격 | 팔레트 제한 | 우선순위 | 연결 방법 |
|---|---|---|---|---|---|
| `sprites.png` | 바탕화면 아이콘 4종(기록 폴더·음악 스피커·도구 시계·방명록 편지), 스피커 재생 프레임 2장, 마스코트 고양이 ‘모모’ 3프레임 | 16×16 논리 픽셀 칸 9개를 **가로 한 줄**로 이어 붙인 144×16 PNG, 1배 크기, 투명 배경. 칸 순서: `folder, speaker, speakerOn, speakerOn2, clock, letter, cat, catBlink, catHappy`. 화면에서는 데스크톱 3배(48px)·모바일 2배(32px)로 정수 확대만 함 | 외곽선 `#26372E` 1px · 밝은 면 `#FAFBF7` · 명암(오른쪽·아래 한 줄) `#C8CFC9` · 포인트 `#385AC8`. 바탕색 `#E7ECE7`과 반투명 픽셀은 쓰지 않음 | 권장 | `ASSETS.spriteSheet = 'assets/sprites.png'`. 칸 순서를 바꿨다면 `ASSETS.spriteOrder`도 같이 수정. **시계 칸은 바늘 없이 얼굴만** 그리면 바늘은 코드가 현재 시각으로 그려요 |
| `audio/<곡 id>.mp3` | 플레이어·채널 목록에서 재생되는 실제 곡 (현재 4채널 20곡, id 예: `dawn-1`, `rain-3`, `focus-2`) | MP3 192kbps 또는 AAC(.m4a), 44.1kHz 스테레오, 곡끼리 음량을 비슷하게(약 -16 LUFS). ‘집중 50분’ 채널은 4곡 합계 50분 | — | 필수 (실서비스) | `ASSETS.tracks = { 'dawn-1': 'assets/audio/dawn-1.mp3', … }`. 파일이 연결된 곡은 `<audio>`로 재생되고 ‘데모 모드’ 표시가 자동으로 사라져요. 곡 제목·길이는 `main.js`의 `CHANNELS`에서 수정 |
| `og-image.png` | 링크 공유 미리보기 | 1200×630 PNG. 소개 창이 보이는 첫 화면 캡처 + 모모 도트(정수 배율) | 위 4색 + `#C8CFC9` | 선택 | `index.html` `<head>`에 `<meta property="og:image" content="assets/og-image.png">` 추가 |

도트 그림 공통 규칙: 한 칸 = 한 픽셀, 외곽선은 항상 1px `#26372E`, 빛은 왼쪽 위에서 오고 명암은 오른쪽·아래 안쪽 한 줄만 `#C8CFC9`. 안티에일리어싱·흐림·반투명 금지.

## 2. 의뢰인이 준비할 내용 (파일 외)

- **이름·문구 확정**: 서비스 이름(현재 가칭 HIDEOUT.FM / 작은 작업실), 한 줄 소개, 운영자 이름과 소개 한 문장, 업데이트 요일·시간.
- **채널 정보**: 채널 4개의 이름·한 줄 설명·분위기 태그, 채널별 곡 목록(제목·아티스트·길이). 현재 곡·아티스트 이름은 모두 예시예요.
- **음원 사용 권리**: 직접 만든 곡인지, 라이선스 곡이라면 웹 스트리밍·반복 재생 허용 범위와 표기 문구.
- **기록 글**: 최신 기록 5편 이상의 제목·날짜·태그·본문(3~5문단)과 어울리는 채널. 글은 `index.html`의 `<article class="post">`에서 바꿔요.
- **방명록 운영 방식**: 지금은 방문자 브라우저(localStorage)에만 저장되는 데모예요. 모두가 보는 방명록이 필요하면 저장 서버(예: Firebase Firestore)와 신고·삭제 정책, 개인정보 안내 문구가 필요해요.
- **멤버십**: 가격, 혜택 3가지, 모집 일정, 결제·신청 링크 (현재 ‘월 3,000원’은 예시).
- **링크**: 연락처 이메일, SNS·외부 채널 주소, 개인정보처리방침(방명록을 서버에 저장할 경우).
